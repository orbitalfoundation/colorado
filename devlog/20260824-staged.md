# 2026-08-24 — staged: colorado.exe.xyz

Phase 2 and a first playable page landed the same evening.

## Allocation solver (`lib/allocate.mjs`)

Three regimes over verified entitlements (CA 4.4 / AZ 2.8 / NV 0.3 / Mexico
1.5 MAF): proportional; a *labeled* party-level stylization of applicable law
(AZ → NV → Mexico → CA, from CAP's 1968 juniority); and the post-2026
framework — the states' negotiated split for the first 1.5 MAF (AZ 760 / CA
440 / NV 50 / MX 250 KAF), seniority beyond, per the ROD. Cuts conserve mass
(checked). The table it produces is the story: at 70% flow, seniority erases
Arizona while California loses nothing.

Read first-hand from the ROD (now in `reference/usbr/`): Interior adopted
*sideboards* (LB shortages to 3.6 MAF, Powell releases 5–12 MAF), not
specific distributions — those come in 2-year Operating Guidelines,
consensus-first. "Era of near-continuous negotiation" is structurally true.

## The page (`site/`)

Hand-coded static ES modules, no build step — the model itself runs
client-side (engine + solver imported directly; data fetched as baked JSON).
Follows the house UX doctrine recovered today from the 2026 devlogs (now
summarized in ~/projects/CLAUDE.md): system light/dark, mobile-first, system
font stacks, space-not-lines, floating mark instead of a header, one accent,
sober instrument copy (the "less game-like" reservation applied — no
challenge framing, just "set the flow, choose the rule"). Scenario state
serializes to the URL. Charts follow the dataviz skill: validated categorical
palette in fixed party order, ink-colored direct labels, single-series line
with crosshair hover, thin bars.
